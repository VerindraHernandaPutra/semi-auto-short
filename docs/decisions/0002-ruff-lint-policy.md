# 0002 — Ruff lint and format policy

Status: accepted (2026-10-28)

## Context

CLAUDE.md requires `ruff` for formatting and linting, but the repo had no configuration and
`ruff` was not a dependency. Its default rule set produced 107 findings, mostly noise.

## Decision

- `ruff` is a dev dependency; line length 100, target `py312`.
- Rules: `E`, `F`, `I`, `UP`, `B`. Alembic `versions/` is excluded (autogenerated).
- Ignored on purpose:
  - `B008` — FastAPI `Depends`/`File` and Typer `Option`/`Argument` use calls in defaults by design.
  - `E501` — `ruff format` does not wrap long strings; the formatter owns line breaks.
  - `UP042` — `JobState(str, Enum)` stays; `StrEnum` changes `str()` behaviour and
    would touch persisted state values.

## Consequences

- `uv run ruff check .` and `uv run ruff format --check .` must pass before each commit.
- Stricter rules (`BLE`, `TRY`, `SIM`) can be adopted later through a new ADR.
